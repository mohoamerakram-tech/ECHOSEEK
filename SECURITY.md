# Security and Responsible Disclosure

This repository contains documentation and sanitized evidence only. It does not contain a runnable product or a supported software package.

## Reporting a problem

If you notice that a published file accidentally exposes personal data, infrastructure details, credentials, or operational content, please open a GitHub issue containing only the filename and a short description. Do not copy the sensitive value into the issue.

## Requests that will not be fulfilled

For safety and confidentiality, I will not provide:

- source code or compiled binaries;
- payloads or command-and-control configuration;
- step-by-step reproduction or deployment instructions;
- unredacted infrastructure evidence;
- techniques intended to defeat a current security product.
